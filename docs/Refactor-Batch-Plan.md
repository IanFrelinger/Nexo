## Refactoring Patterns

### **Service Files** → Orchestrator + Partial Classes
- Convert main class to `partial class` orchestrator
- Split functionality into logical partial classes
- Maintain clean separation of concerns
- Preserve Unity MonoBehaviour/EditorWindow structure where applicable

### **Test Files** → Success/Error/Cancellation Categories
- Convert main test class to `partial class` orchestrator
- Split tests into Success, ErrorHandling, and Cancellation partial classes
- Maintain test organization and readability
- Preserve test functionality and coverage

### **Interface Files** → Partial Interfaces
- Convert main interface to `partial interface` orchestrator
- Split interface methods into logical partial interfaces
- Maintain interface contracts and implementations
- Preserve interface hierarchy and relationships
