## Notes

- All new features should follow Clean Architecture principles
- Maintain SOLID principles in all implementations
- Use Strategy pattern for extensibility (OCP)
- Keep Application layer host-agnostic
- Return DTOs, never domain entities from Application layer
- Use MediatR for all use cases
- Use FluentValidation for all input validation
