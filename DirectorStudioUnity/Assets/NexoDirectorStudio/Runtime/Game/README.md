# Doom FPS Game - Unity Integration

This directory contains the Unity integration for the Doom-style FPS game generated by Director Studio.

## 🎮 Game Components

### Core Game Scripts
- **`DoomFPSGame.cs`** - Main game controller that manages the entire game state
- **`DoomGameLauncher.cs`** - Launches the game using Director Studio generated content
- **`DoomSceneSetup.cs`** - Sets up the Unity scene for the game

### Game Objects
- **`DoomTile.cs`** - Represents world tiles (walls, floors, platforms, hazards)
- **`DoomEnemy.cs`** - Enemy AI with patrol, detection, and attack behavior
- **`DoomWeapon.cs`** - Weapon system with different weapon types
- **`DoomPowerUp.cs`** - Power-ups (health, armor, ammo, speed, damage)
- **`DoomGoal.cs`** - Level completion goal/exit
- **`DoomHazard.cs`** - Environmental hazards that damage the player
- **`DoomPlatform.cs`** - Moving platforms and jump pads

### UI System
- **`DoomFPSUI.cs`** - Complete HUD system with health, armor, ammo, time, and crosshair

## 🚀 How to Play

### Setup Instructions
1. Create a new Unity scene
2. Add the `DoomSceneSetup` script to any GameObject
3. The game will automatically launch when you play the scene

### Controls
- **WASD** - Move
- **Mouse** - Look around
- **Space** - Jump
- **Left Click** - Fire weapon
- **E** - Interact with objects
